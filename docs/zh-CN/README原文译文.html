AERIS-10 开源脉冲线性调频相控阵雷达

原文：合并前的 README.md，英文快照保存在 sources/README.en.md，版本指纹见同目录 源文件基线.json。本文件翻译本轮起始版本，原文中的性能、完成状态、许可证解释及社区数据均为原作者陈述，未经本轮硬件实测或联网核实。原文型号 AERIS-10E 与 AERIS-10X 的混用予以保留。

原文徽章：GitHub 星标、分叉、关注；软件 MIT；硬件 CERN-OHL-P；状态 Alpha；功能仍在开发；频率 10.5GHz；欢迎提交 PR。徽章对应的在线数据不在本次核查范围内。

AERIS-10 是一个开源、低成本的 10.5 GHz 相控阵雷达系统，采用脉冲线性调频（LFM）调制。它提供两个版本，标称探测距离分别为 3 km 和 20 km，面向希望探索和试验相控阵雷达技术的研究人员、无人机开发者和资深软件定义无线电（SDR）爱好者。

概述

AERIS-10 项目希望通过完全开源、模块化、可供修改的雷达系统，让更多人接触雷达技术。大学研究人员、无人机初创企业和高级创客可以用这个平台试验波束成形、脉冲压缩、多普勒处理和目标跟踪。

主要功能

  • 开源硬件和软件：原文称提供完整的原理图、PCB 布局、固件和软件。
  • 两个版本：AERIS-10N（Nexus）采用 8×16 贴片天线阵列，标称距离 3 km；AERIS-10E（Extended）采用 32×16 介质填充缝隙波导阵列，标称距离 20 km。
  • 全电子波束转向：俯仰和方位方向均为 ±45°。
  • 高级信号处理：板载 FPGA 完成脉冲压缩、多普勒 FFT、MTI 和 CFAR。
  • Python 图形界面：提供地图集成的用户界面。
  • GPS/IMU 集成：实时位置与姿态修正。
  • 模块化设计：独立的电源管理、频率合成和射频电路板。

系统架构

硬件组成

电源管理板为各电子元件提供所需电压，并进行适当滤波和时序控制；时序由微控制器保证。

频率合成板采用高性能、低抖动时钟发生器 AD9523-1，为接收和发射频率合成器 ADF4382、DAC、ADC 和 FPGA 提供相位对齐的参考时钟。

主板包含以下部分：

  • DAC：产生雷达线性调频信号。
  • 两个 LTC5552 微波混频器：完成上变频和中频下变频。
  • 四个四通道 ADAR1000 移相器：完成接收和发射链路波束成形。
  • 十六个 ADTR1107 前端芯片：兼用于接收链低噪声放大和发射链功率放大。
  • XC7A50T FPGA：位于上游 FTG256 板，负责通过 DAC 产生 PLFM 线性调频信号、读取 ADC 原始数据、跨 FPGA/STM32/GUI 的混合自动增益控制（AGC）、I/Q 基带下变频、抽取、滤波、正向 FFT、脉冲压缩、多普勒/MTI/CFAR 处理和 USB 接口。
  • STM32F746xx 微控制器：负责上电与断电时序（参见电源管理 Excel 表）、与 FPGA 通信及各外围器件的配置和连接。

STM32 所管理的器件与功能包括：

  • AD9523-1 时钟发生器。
  • 两个 ADF4382 频率合成器。
  • 四个四通道 ADAR1000 移相器，用于雷达脉冲时序。
  • 两个八通道 I²C ADC ADS7830：主板 U88 地址 0x48、U89 地址 0x4A，测量 16 个功放通道的静态电流 Idq。每个通道使用功放板上的 5 mΩ 分流电阻和主板上的 INA241A3 电流检测放大器（50 倍增益）。
  • 两个八通道 I²C DAC DAC5578：主板 U7 地址 0x48、U69 地址 0x49，控制 16 个功放通道的栅极电压 Vg；启动时通过闭环校准到目标 Idq。
  • UM982 GPS 模块：用于界面地图居中及每次检测的位置标记。
  • GY-85 IMU：修正目标坐标中的俯仰和横滚。
  • BMP180 气压计、步进电机及射频开关。
  • 一个八通道 I²C ADC ADS7830（主板 U10）：读取八个热敏电阻进行温度监测；任一通道超过阈值时，通过单个 GPIO EN_DIS_COOLING 打开冷却风扇。

十六块功率放大器板仅用于 AERIS-10E，使用 10 W 的 QPA2962 GaN 放大器以延长探测距离。

天线阵列：AERIS-10N（Nexus）使用 8×16 贴片阵列；AERIS-10X（Extended，原文此处如此命名）使用 32×16 介质填充缝隙波导阵列。其他组件包括滑环、步进电机及其驱动器、冷却风扇和外壳。

处理流程

  1. 波形生成：DAC 产生 LFM 线性调频信号。
  2. 上下变频：LTC5552 混频器完成频率转换。
  3. 波束转向：ADAR1000 移相器控制 16 个阵元。
  4. FPGA 信号处理：采集 ADC 原始数据，进行 I/Q 基带下变频、CIC/FIR 抽取与滤波、脉冲压缩、多普勒 FFT、MTI 与 CFAR 检测。
  5. STM32 系统管理：电源时序、外设配置、GPS/IMU 集成、步进电机控制。
  6. Python GUI 可视化：实时目标绘图、地图集成和雷达控制界面。

原文展示 V6 界面动画，但紧随其后的 HTML 注释写明：V6 已弃用，当前使用 V65 Tk 和 V7 PyQt6。本地动画见 9_Firmware/9_3_GUI/GUI_V6.gif。

入门

仓库文件存放规则

为保持仓库根目录整洁并便于查找产物，生成文件应放在以下位置：

  • 已发布、纳入版本控制、供 GitHub Pages 使用的报告放在 docs/，例如 docs/AERIS_Simulation_Report_v2.pdf。
  • 本地仿真生成结果放在被 Git 忽略的 5_Simulations/generated/，包括图表、场景输出和临时分析目录。
  • 本地 FPGA/Vivado 生成产物放在被 Git 忽略的 9_Firmware/9_2_FPGA/reports/，包括 VCD/VVP、临时 CSV 和本地报告快照。
  • 可复用、纳入版本控制的 FPGA 自动化脚本放在 9_Firmware/9_2_FPGA/scripts/，包括 TCL 流程及构建、上板辅助脚本。

不要把生成产物留在仓库根目录。

前置条件

  • 基本雷达原理知识。
  • 构建硬件时所需的 PCB 装配经验。
  • GUI 软件需要 Python 3.8+（译注：pyproject.toml 实际声明 >=3.12，要求不一致）。
  • 修改信号处理时需要 Vivado 等 FPGA 开发工具。

硬件装配

  1. 订购 PCB：制造输出位于 4_Schematics and Boards Layout/4_7_Production Files/。
  2. 采购元件：BOM/CPL 与制造输出位于同一目录。
  3. 装配：配合使用 4_Schematics and Boards Layout/4_6_Schematics/ 中的原理图及上述制造文件；当前没有纳入版本控制的独立装配指南。
  4. 天线：按目标版本选择合适的阵列文件。
  5. 外壳：机械图纸当前位于 8_Utils/Mechanical_Drawings/。

许可证

以下为原文说明的翻译。仓库中的实际文本另见 Licence 本地文本译文；本次没有核实其是否与官方版本一致。

项目开源，但硬件和软件采用不同许可证，以覆盖各自需要。

硬件文档

硬件设计文件，包括原理图与 PCB 布局、BOM、Gerber 与制造输出、机械图及外壳设计，采用 CERN 开放硬件许可证第 2 版宽松型（CERN-OHL-P）。

原文称该硬件专用许可证明确界定“硬件”“文档”“产品”，包含面向贡献者和用户的专利保护，提供更强的责任限制（与高功率射频相关），并与 CERN、OSHWA 等开放硬件规范相符。

原文称，可以使用、修改并销售基于这些设计的产品，条件是保留原版权声明、以同一许可证分发修改后的设计，并以源文件形式提供修改。

软件和固件

FPGA 代码（9_Firmware/ 中的 VHDL/Verilog）、STM32 固件、Python GUI 与工具继续采用 MIT 许可证，以保留较大使用灵活性。

完整许可证文本

原文称完整 CERN-OHL-P 文本位于 LICENSE 文件；软件在没有其他声明时适用 MIT 条款。译注：本地实际文件名为 Licence，没有同名 LICENSE 文件。

为什么更改许可证

项目最初整体使用 MIT。社区（原文特别感谢 gmaynez）指出 MIT 缺少实体硬件所需的法律保护；原文称改用 CERN-OHL-P 可以在保留宽松精神的同时提供适当保护。
