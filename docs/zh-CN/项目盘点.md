## 项目目标与实现边界

原 README 描述的是 10.5 GHz 脉冲线性调频相控阵雷达，提供标称 3 km 和 20 km 版本。其 Alpha/开发中徽章与末尾说明表明仍在开发。3 km、20 km、±45°、输出功率等是原文指标；本轮没有雷达外场、暗室、射频或板卡实测，不能写成已实现性能。

按现有源码与文档，系统由电源及频率合成、射频与阵列、STM32 管理、FPGA 数字信号处理、Python 主机界面组成。FPGA 处理链涉及 ADC、数字下变频、抽取/滤波、匹配滤波与脉冲压缩、距离/多普勒处理及检测。详细源码边界见 [固件实现与验证盘点](firmware/实现与验证盘点.md)。

MCU 目录包含外围器件驱动、STM32 管理源码及主机 mock 测试。FPGA 包含核心顶层、50T/200T/Trenz 目标封装、XDC、回归脚本和测试平台。GUI 有 V65 Tk 和 V7 PyQt6 入口，V6 被说明文件标为弃用。文件存在和源码包含模块，只能证明材料与实现入口存在，不能证明板上功能完成。

制造文件已按板卡分目录存放；原理图存在 `.sch/.brd` 和 KiCad 格式。贡献指南将布局概括为 KiCad，阅读工程时需按实际格式选择工具。原文也明确没有独立装配指南。未对 Gerber、电气规则、BOM 一致性、阻抗或制造可行性作专项复核。

## 已发现的差异

| 问题 | 可核对证据 | 对理解项目的影响 |

| 型号名称不一致 | README 的扩展版本交替使用 AERIS-10E 和 AERIS-10X | 不能据此假定是两个独立硬件版本 |
| Python 要求不一致 | README 写 3.8+；`pyproject.toml` 写 `>=3.12` | 新环境应先以实际工程配置核对依赖；译文同时保留两者 |
| 验证状态不同步 | 主页与上板页仍为 Build 16、MCU 15/15、FPGA 18/18；实施日志与报告页已出现 Build 25、20/20、23/23 | 网站各页不是统一的当前基线，均不能替代本轮重跑 |
