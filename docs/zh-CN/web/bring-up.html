板卡到货冒烟测试

  1. 上电前检查载板默认配置、稳压器使能、跳线及所有板级时钟源选择。
  2. 以最安全配置为载板和模块上电，保持射频发射路径禁用，立即记录电流。
  3. 执行 FPGA 烧录流程，验证 JTAG 枚举，并通过硬件管理器脚本确认 DONE 和 INIT_COMPLETE。
  4. 在使能任何依赖模拟或射频的功能前，检查确定的复位释放和心跳/状态输出。
  5. 启用 MCU 固件日志，确认 AD9523 状态引脚、LO 初始化结果以及波束形成器通信回读。
  6. 使用带调试能力的 FPGA 镜像和探针，依次确认原始 ADC、DDC、匹配滤波器和 USB 路径活动。
  7. 在任何长时间流式传输测试前，按已知帧结构预期检验 FT601 路径。
  8. 仅在前面所有步骤通过后，开始 PA 偏置、校准和风险更高的射频激活。

中止标准

  • 出现意外电源轨电流、稳压器不稳定，或温升超过计划空闲范围时，立即停止。
  • 若锁定 GPIO 与锁定状态回读反复不一致，不得越过 LO 上板调试阶段继续。
  • 若任一波束形成器的 scratchpad/回读检查失败，停止射频激活。
  • 若帧结构、背压或总线方向行为不一致，不得继续 USB 压力测试。
  • 若复位时序或时钟存在性不明确，退回心跳或调试镜像。
  • 调整上板调试专用目标时，保持生产目标约束和引脚分配源文件不变。

主机端工具和工作流程

  • 使用已提交 Vivado TCL 脚本及 2026-03-21 构建的 TE0713 心跳基线进行 JTAG 烧录。
  • 在 USART3 采集串口日志，保留上板调试日志时间戳。
  • 使用 FT601 或主机 USB 采集/解码流程，验证帧结构和载荷稳定性。
  • 使用 ILA 采集流程，检查原始 ADC、DDC、匹配滤波器和 USB 时钟域检查点。
  • 为基线镜像、调试镜像和回退镜像选择准备可重复的检查清单。

板卡到货前已知开放风险

风险 当前状态 Day-0 处理
FT601 方法学遗留警告 生产目标 XDC 清理已验证，但仍记录一个 ft601_txe 方法学遗留项。 视为已知观测项；进一步改动约束前，先验证实际 FT601 状态行为。
射频控制路径真实性 固件顺序和诊断已改善，但 LO 同步、相位行为和波束形成器控制仍需物理验证。 上板调试优先回读，不得仅凭仿真或日志假定模拟行为。
原型级顶层功能假设 活动 FPGA 基线回归通过，但某些雷达功能行为仍需在实际 I/O 条件下进行真实板卡确认。 在宣称完整流式传输能力前，用 ILA 和主机采集逐级验证数据路径。
PA 校准边界 IDQ 校准逻辑比之前安全得多，但真实器件收敛及裕量限制尚未经板卡验证。 采用保守限制，逐通道观测，异常电流或通道不收敛时停止。
板卡专用集成未知项 载板/模块交互、电源轨、时钟及连接器假设仍有部分需在首次装配后验证。 启用更高能量子系统前，先从已跟踪 TE0713/TE0701 心跳镜像和配置检查开始。
