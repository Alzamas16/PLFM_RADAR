# 工程文档站点

开源相控阵雷达。

本站跟踪 AERIS-10 的架构、已验证的实现基线、约束清理进展以及硬件到货前的上板调试准备情况。

[查看变更时间线](implementation-log.md) · [打开准备资料包](bring-up.md)

## 生产板 USB

**FT2232H（USB 2.0）**

50T 生产板使用 FT2232H。FT601 USB 3.0 仅在 200T 高配开发板上提供。

## 跟踪的时序基线

**WNS +0.058 ns**

移植已验证的 Build 16 XDC 后，WHS +0.068、WPWS +0.684。

## 回归状态

**MCU 15 / 15，FPGA 18 / 18**

主机端固件回归测试以及 FPGA 单元和集成测试套件均通过。

## 方法学状态

**XDCB-5 = 0**

仅剩一个已记录的 TIMING-18 问题，涉及 `ft601_txe` 异步观测。

## 当前阶段

**硬件到货前准备**

板卡到货冒烟测试、产物清单以及开放风险跟踪均已准备。

## 近期变更

- 将已验证的 Build 16 生产目标 XDC 清理结果移植到跟踪仓库。
- 保持布局布线后的正时序裕量，同时清除 XDCB-5，并将方法学遗留问题减少为一个已记录条目。
- 通过 MCU 主机回归测试及 FPGA 回归/集成测试套件验证跟踪分支。
- 将上板调试文档更新为 FPGA 模块和载板到货前的准备资料包。
- 暂不将上游 ADAR1000 整批导入内容纳入基线，仅在有充分理由时选择性复用。
