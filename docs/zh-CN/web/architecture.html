顶层处理流程

阶段 重点模块 说明
ADC 采集 AD9484 接口 + CDC 边界 400 MHz 采样时钟域，同步到处理流水线。
DDC NCO + CIC + FIR I/Q 转换和抽取，生成可供基带处理的数据流。
匹配滤波器 基于 FFT 的处理链 综合分支是硬件等效联合仿真的黄金参考。
距离/多普勒 距离单元抽取器 + 多普勒 FFT 每帧 32 个 chirp、64 个距离单元，帧输出确定。
主机路径 FT601 接口 USB 流式传输，上板调试中进行帧结构和长时间稳定性验证。

当前目标拆分策略

  • 生产目标仍为 xc7a200t-2fbg484i，使用完整板级约束。
  • TE0712/TE0701 和 TE0713/TE0701 使用专用顶层封装和专用 XDC 文件。
  • 板卡专用引脚分配与核心 DSP 模块隔离，避免意外引入跨目标回归。
  • 上板调试从最小心跳顶层开始，然后逐步进入完整信号链验证。
