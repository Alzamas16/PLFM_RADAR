## 此比特流的功能

- 通过轻量封装 `radar_system_top_te0713_umft601x_dev.v`，实例化 `usb_data_interface.v`（完整 FT601 USB 数据通路）。
- 生成合成测试数据：距离剖面数据包（计数器 XOR 模式），以及可选的多普勒和 CFAR 数据包，由主机命令控制。
- 响应 USB 主机命令（流控制 `0x04`，状态请求 `0xFF`）。
- 以约 6 Hz 心跳驱动 `ft601_gpio0`（计数器第 24 位）。
- 上电复位结束后驱动 `ft601_chip_reset_n`（32k 个时钟周期）。
- `ft601_wakeup_n` 保持高电平（非活动状态）。

## 硬件配置

1. 将 TE0713-03 安装在 TE0701-06 载板上。
2. 将 UMFT601X-B 插入 TE0701 J10（FMC LPC 连接器）。
3. TE0701 VIOTB = 3.3V（跳线配置）。
4. UMFT601X-B 跳线：JP1=开路，JP2=2-3，JP3=开路，JP6=短接（3.3V），JP4=2-3，JP5=2-3（245 同步 FIFO 模式）。
5. 使用 USB 3.0 Micro-B 电缆将 UMFT601X-B 连接到主机 PC。
6. 使用 Trenz 编程 USB 进行 JTAG 操作。

## 验证步骤

1. 烧录后检查 `ft601_gpio0` 是否翻转（约 6 Hz），以确认 FPGA 正在运行。
2. 主机 PC 上应将 FT601 枚举为 USB 3.0 设备（VID `0x0403`，PID `0x601F`）。
3. 使用 FTDI D3XX 驱动 / `ftd3xx` Python 库读取数据：
   - 打开设备，将管道设为通道 0。
   - 读取应返回包含测试模式数据包的 32 位字。
   - 数据包头：`0xAE10xxxx`，其中 `xxxx` 为数据包类型。

## 时序收敛说明

此前的构建因源同步时钟偏斜未满足建立时间：

- FT601 时钟经 IBUF+BUFG 输入，插入延迟约 5 ns。
- 参考 `ft601_clk_in` 的 `set_output_delay` 造成约 5 ns 的虚假偏斜惩罚（源端有插入延迟，端口处的目的端为 0）。
- 修复方式是对输出约束使用 `set_max_delay -datapath_only`，直接约束寄存器到焊盘的路径，预算为 7.5 ns。
- 输入延迟仍使用参考 `ft601_clk_in` 的 `set_input_delay`；其方向正确，即由 FT601 驱动数据，FPGA 在 IBUF+BUFG 后采样。
